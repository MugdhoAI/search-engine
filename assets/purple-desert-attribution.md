# Background video attribution

The Purple Desert background video was provided by the project owner. The source description supplied with the file credits GetLayers: [getlayers.ai/layer/purple-desert](https://www.getlayers.ai/layer/purple-desert).

The app uses a web optimized, silent H.264 copy of the supplied clip plus a poster frame extracted from its opening. The original supplied file is 2888 × 2160, 30 fps, and approximately 8.7 seconds long. The included playback copy preserves its aspect ratio and duration while removing the audio track and reducing transfer size for browser playback.
